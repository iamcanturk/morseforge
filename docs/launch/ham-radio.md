# Ham radio forums and clubs

This is the audience whose opinion counts most and who are slowest to trust
a newcomer. Two rules:

1. **Ask before you announce.** In forums, frame the post as a request for
   review by operators, which is honest (Can isn't licensed and wants
   corrections). In clubs, write to a person, not a mailing list.
2. **Never position it against their way of teaching.** CW clubs have
   long-standing methods (CW Academy, LICW's instinctive approach, Koch
   trainers). MorseForge is a free extra for the first week, not a
   replacement.

## QRZ Forums (forums.qrz.com)

**Rules** *(verify)*: posting needs a QRZ account; there is a section for CW.
Commercial advertising is not allowed, but a free, open-source tool posted by
its maker for feedback is the kind of thing these sections discuss. Read the
section's pinned rules first. If in doubt, ask a moderator.

**Title**

> Free browser CW trainer for beginners: looking for operators to check the
> on-air material

**Body**

> Hello all. I've built a free, open-source Morse trainer that runs in a web
> browser (no install, no account, works offline):
> https://morse.iamcanturk.dev
>
> It's aimed at the first week: characters taught by sound in code-length
> order, Farnsworth spacing by default, and sending with the keyboard or a
> phone screen as a straight key. There's also copy practice on code groups,
> common words, on-air phrases and callsigns.
>
> I'm working towards my amateur radio certificate in Turkey (my sailing course
> requires it), so I'm not licensed yet and I'm sure some of the on-air
> material can be improved:
> the prosigns (AR, SK, BT and the others), the Q-codes, and how a typical
> exchange is phrased. If anyone has ten minutes to look and tell me what's off,
> I'll correct it.
>
> It keys as a straight key or as iambic paddles (A and B, dot/dah memory;
> USB paddle adapters map to Left/Right Ctrl). Paddle keying is new, so a
> paddle user's opinion on the timing would be especially welcome. It's
> English only for now.
>
> Source (MIT): https://github.com/iamcanturk/morseforge
>
> Thanks. Can

Sign off with a name. Without a callsign, a name is the honest signature.
